# Python Data Science and Machine Learning Guide

An interactive web guide that showcases Python libraries and functions organized according to the CRISP-ML(Q) methodology for Machine Learning projects.

## 🌟 Features

- **CRISP-ML(Q) Structure**: Content organized following the Cross-Industry Standard Process for Machine Learning
- **Interactive Navigation**: Easy-to-use sidebar navigation with detailed function documentation
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Detailed Documentation**: Comprehensive information about Python libraries and functions
- **Code Examples**: Practical examples for each function

## 🚀 Project Structure

```
.
├── index.html              # Main page with CRISP-ML(Q) phases overview
├── data-understanding.html # Detailed page for Data Understanding phase
├── styles.css             # Global styles
├── script.js              # Interactive functionality
└── README.md             # Project documentation
```

## 📋 Pages

1. **Main Page (index.html)**
   - Overview of all CRISP-ML(Q) phases
   - Quick access to main libraries and functions
   - Links to detailed phase pages

2. **Data Understanding (data-understanding.html)**
   - Comprehensive guide to data exploration
   - Detailed function documentation
   - Interactive sidebar navigation
   - Code examples

## 🔧 Local Development

1. Clone the repository:
```bash
git clone https://github.com/yourusername/python-ml-guide.git
```

2. Open the project in your preferred code editor

3. Start a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000
```

4. Visit `http://localhost:8000` in your browser
